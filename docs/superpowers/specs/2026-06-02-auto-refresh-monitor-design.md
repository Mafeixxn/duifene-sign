# 监听 10 分钟自动刷新 设计

## 目标

监听超过 10 分钟后自动停止并重新启动一轮，防止长时间运行导致会话失效或漏签。

## 改动范围

| 文件 | 改动 |
|------|------|
| `windows/sign_service.py` | 加计时和自动刷新逻辑 |
| `windows/app.py` | 不改 |

## 逻辑

1. `start_monitoring()` 记录 `_start_time`
2. 每次 `_tick()` 检查运行时长是否超过 600 秒
3. 超过则日志愿 "监听已运行10分钟，自动刷新..."，重进课程，重置计时和已签到记录
4. 刷新失败则告辞但不中断，保留旧会话继续

## 边界

- 手动停止 → 计时结束
- 手动重新开始 → 计时重置
- 刷新失败 → 日志告警，继续使用旧会话轮询
- 刷新成功 → 清空 `_checked_ids`，避免误判重复签到
